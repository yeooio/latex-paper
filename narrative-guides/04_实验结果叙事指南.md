# 第 4 章实验结果叙事指南

## 本章要传递的核心信息

> 主对比、代表性轨迹、消融和复杂度共同说明方法有效且轻量；跨数据集实验进一步界定这种优势不能自动转化为无条件跨域泛化。

## 审阅时的首要判断

复杂度分析首先要让审稿人理解研究为什么有价值、轻量化设计具体做了什么，以及精度改善是否依赖扩大模型规模。正文应以“研究问题—统一比较—关键结果—精度与开销权衡”推进，不以解释“作者为什么这样做没有错”为主线。公平性、工具选择和参数设置只保留影响比较口径与结果解释的必要信息；不得为了预防假想质疑而堆叠重复比例、额外自证或缺少证据的硬件部署推断。

## 每类实验回答什么

| 实验 | 唯一主要问题 |
| --- | --- |
| 多电池主对比 | 模型在同一数据域不同电池上的估计表现如何 |
| 代表性曲线 | 优势体现在哪类退化形态 |
| 消融 | 收益来自哪些模块及组合 |
| 卷积尺度 | 短核、长核和双尺度怎样互补 |
| 复杂度 | 精度是否依赖扩大模型规模 |
| 跨数据集 | 域内优势能否延伸到异质目标域 |
| 超参数/收敛 | 结果是否依赖偶然配置，训练是否稳定 |

## 范文如何传递

BMSFormer 围绕准确性、效率、稳定性和跨电池泛化排列实验，每项直接兑现引言中的一个问题。

师兄稿按突降、平滑衰减、容量恢复和加速尾部组织曲线讨论，使模块价值对应可观察退化困难；后续统计、校准、延迟和 MCU 属于其强工程主张及修回补证层。

## 当前稿件的主要状态

优点：主对比、迁移、消融、尺度和复杂度证据完整；CX2现象讨论较好；跨域负结果表述诚实；复杂度部分承认训练时间并非最快。

## 复杂度分析的叙事边界

复杂度分析采用“比较目的与统一条件 → 核心复杂度结果 → 模型宽度变化 → 精度—开销结论”的单向推进。实验环境、统计工具、训练设置、输入形状和结构尺度属于必要协议，应集中写入统一配置段，不拆成多段操作记录。对于直接影响 FLOPs 和参数量的输入规模、卷积核、步长等配置，可按照复杂度范文的颗粒度保留确切数值；已有模型表或引文能够承载的结构背景不再重复展开其功能原理。

三类范文信息分别取舍如下：

- 完整复杂度范文用于确认应报告 FLOPs、训练时间、参数量、存储和统一配置；按用户确认保留测量库及函数说明，不继续扩展工具常识、双配置复述和逐层结构记录；
- BMSFormer 用于学习先说明非最优训练时间、再回到 FLOPs、参数量和存储优势的结果组织，不继承对训练时间差异的未经验证机制归因；
- SL-AgentNet 的延迟协议、吞吐量、预热次数和硬件适配结论仅适用于实际推理延迟或嵌入式测试，不得用训练时间替代推理延迟，也不得在缺少硬件证据时扩展为实时部署主张。

复杂度结果正文只保留能够回答“精度是否依赖扩大模型规模”的代表性数字。表格已经完整列出全部模型时，不逐模型复述所有数值和降低率；模型宽度实验用一个端点结果和整体趋势说明存储优势是否稳定，避免图中范围、端点和最终结论重复三次。

## 用户确认的复杂度范文解释深度（2026-09-12）

复杂度结果不能仅列出最低值、百分比和一句“取得平衡”。按用户最新确认，解释深度落实为本段内的效率、退化刻画能力与整体估计表现之间的比较，不额外加入DSConv、RAA的结构介绍或“成本与表征”机制解释，也不借“前述实验”“结合消融”等回顾性表述组织本段。该要求取代此前建议添加一至两句结构与消融解释的方案。

- 完整复杂度范文：协议保留测量工具、训练设置和输入；结果采用绝对量与代表性降幅；解释推进到架构紧凑性与资源需求。
- BMSFormer：以训练时间与估计表现的对照建立权衡，再以同一基线中的有利、不利指标展开比较；学习其表征能力解释层，不继承“顺序结构必然使训练更快”的未经验证归因。
- SL-AgentNet：先将低计算量、延迟与估计误差联系，再解释资源与估计表现的权衡。本文学习其就地讨论能力与表现的写法，不添加结构机制段，不移植其累计FLOPs、推理延迟、MCU、RTOS或车辆安全结论。
- 保留THOP的profile、Python的time、torchsummary的summary和os.path.getsize完整说明；统一训练条件和输入压缩为用户给出的两句，删除正文中的基线层数、卷积核与步长清单。
- 百分比数量不设机械上限，也不专挑最大降幅；每个比较须承担明确功能。训练时间相近属于结果观察，不是控制条件。
- 结果段不再补充多尺度DSConv或RAA如何降低开销、如何增强表征的介绍；不插入反向传播科普。集中写基线效率优势及估计局限、本文的具体资源优势与整体应用潜力，避免为模仿范文而新增其对应结果段没有承担的论证层。
- 报告四项指标不要求四项均最优。非最优结果陈述一次并接已有证据，不在开头、结果和结尾反复强调“而非训练速度”。

## 非最优与负结果的具体句型

- 直接写“Transformer在Cell8上误差最低”；随后报告宏平均，不辩护。
- 直接写“部分跨域方向R²仍为负，说明当前表示尚不足以解释目标域变化”；不包装成成功。
- 直接写“训练时间并非最低”；再界定轻量化证据来自FLOPs、参数与存储。
