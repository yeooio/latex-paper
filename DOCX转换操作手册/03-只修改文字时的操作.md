# 只修改文字时的完整操作

本文件专门说明一种最常见的情况：论文的图、表、公式和章节结构不变，只修改正文中的句子、段落或参考文献文字。

## 先记住结论

**修改文字后不能只编译 LaTeX。**

LaTeX 编译只会更新 `main.pdf`。最终 Word 文件是另一份独立生成的文件，必须再运行 DOCX 转换脚本。

完整关系是：

```text
修改 LaTeX 文字
    ↓
重新编译 main.pdf
    ↓
运行 tools/build_docx_verified.py
    ↓
复制新的最终 DOCX
```

## 具体步骤

### 第一步：修改源文件

根据文字所在位置修改：

- 摘要：`chapters/abstract.tex`；
- 第 1 章：`chapters/chapter01.tex`；
- 第 2 章：`chapters/chapter02.tex`；
- 第 3 章：`chapters/chapter03.tex`；
- 第 4 章：`chapters/chapter04.tex`；
- 第 5 章：`chapters/chapter05.tex`；
- 参考文献：`backmatter/references.tex`。

不要直接修改 `output/docx_verified/MS-AgentNet_editable_final.docx` 作为长期版本。下一次生成时，DOCX 会由 LaTeX 源文件重新产生。

### 第二步：重新编译 PDF

使用仓库原有的 LaTeX 编译方式重新生成 `main.pdf`。确认：

- `main.pdf` 的修改时间已经更新；
- PDF 能正常打开；
- 新文字已经出现在 PDF 中；
- 没有 LaTeX 致命错误；
- 图表和公式编号没有异常变化。

如果文字增加或减少导致分页变化，这是正常的。表格截图的位置也可能随 PDF 分页重新生成。

### 第三步：重新生成 DOCX

在仓库根目录运行：

```powershell
$py = 'C:\Users\c1342\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $py tools\build_docx_verified.py
```

脚本会重新完成：

- LaTeX → Markdown；
- Markdown → DOCX；
- 正文和标题写入 Word；
- 公式和公式编号写入 Word；
- 普通图片重新插入；
- 表格从新的 `main.pdf` 重新截图；
- 正文引用和参考文献跳转重新建立。

### 第四步：复制最终文件

```powershell
Copy-Item 'output\docx_verified\MS-AgentNet_可编辑论文.docx' `
  'output\docx_verified\MS-AgentNet_editable_final.docx' -Force
```

如果需要保留旧版本，先复制一份并使用日期命名，例如：

```powershell
Copy-Item 'output\docx_verified\MS-AgentNet_editable_final.docx' `
  'output\docx_verified\backup_before_text_change_20260912.docx'
```

## 第五步：只检查受影响的内容

文字修改完成后，至少检查：

1. 修改的句子是否出现在 DOCX；
2. 修改位置前后的标题和段落是否连续；
3. 新增文字是否造成孤立标题或大面积空白；
4. 公式编号是否仍连续；
5. 图题、表题是否仍和对应对象在一起；
6. 正文引用是否仍能跳转；
7. 参考文献编号是否没有断号；
8. DOCX 是否可以正常打开。

如果只是一个普通句子变化，通常不需要重新设计图片或表格；脚本会自动复用源文件中的图片，并从最新 PDF 重新生成表格截图。

## 哪些情况不能只按“文字修改”处理

以下改动虽然看起来只是改文字，但需要额外检查：

- 删除或新增了 `\label{...}`；
- 改动了 `\caption{...}`；
- 改动了公式或公式编号；
- 改动了图表顺序；
- 新增或删除了参考文献；
- 改动了表格内容；
- 改动导致图表跨页或分页明显变化。

这些情况仍然可以运行同一个转换脚本，但必须重点检查编号、跳转、表格截图和分页。

## 最短版本

以后只改文字时，不需要手动处理 DOCX：

```text
改 .tex 文件
→ 编译 main.pdf
→ 运行 tools/build_docx_verified.py
→ 复制 MS-AgentNet_editable_final.docx
→ 检查修改位置和分页
```
