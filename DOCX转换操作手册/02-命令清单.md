# 常用命令清单

## 设置工作区 Python

```powershell
$py = 'C:\Users\c1342\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
```

## 安装 Pandoc 运行包（只需首次执行）

```powershell
& $py -m pip install --target 'tmp\docx-deps' pypandoc_binary
```

## 重新生成 DOCX

```powershell
& $py tools\build_docx_verified.py
Copy-Item 'output\docx_verified\MS-AgentNet_可编辑论文.docx' `
  'output\docx_verified\MS-AgentNet_editable_final.docx' -Force
```

## 检查 DOCX 是否损坏

```powershell
& $py -c "import zipfile; p='output/docx_verified/MS-AgentNet_editable_final.docx'; print(zipfile.ZipFile(p).testzip())"
```

## 查看转换状态

```powershell
Get-Content -Raw output\docx_verified\manifest.json
```

## 重新生成后必须检查

1. 正文是否完整；
2. 公式编号是否连续；
3. Figure 4.2 和 Figure 4.3 是否来自最新 PDF；
4. 表格截图是否清晰；
5. 图题和表题是否与对象保持在一起；
6. 正文引用能否跳到参考文献；
7. 是否出现空白页、图片拉伸或文字溢出。
