# 自动转换流程图

```text
LaTeX 源文件
  ├─ main.tex
  ├─ chapters/*.tex
  ├─ tables/*.tex
  ├─ figures/*.tex + figures/**/*.{png,pdf}
  └─ backmatter/references.tex
          │
          ▼
      编译 LaTeX
          │
          ▼
      main.pdf  ← 视觉基准和表格截图来源
          │
          ▼
  tools/build_docx_verified.py
          │
          ├─ 展开 LaTeX 输入文件
          ├─ LaTeX → Markdown
          ├─ Markdown → DOCX
          ├─ 写入 Word 可编辑公式
          ├─ 写入公式编号和内部书签
          ├─ 写入正文引用和参考文献跳转
          ├─ 从 main.pdf 裁剪表格图片
          └─ 从 figures/ 写入普通图片
          │
          ▼
  output/docx_verified/MS-AgentNet_editable_final.docx
          │
          ▼
  Word 导出 PDF + PNG 视觉检查
```

## 内容和版式分别由谁负责

- LaTeX 源文件负责内容、公式、图表编号和参考文献编号；
- `main.pdf` 负责最终视觉版式和表格截图；
- `tools/build_docx_verified.py` 负责 DOCX 结构、可编辑公式、图片、表格截图和跳转；
- Word 渲染负责发现分页、拉伸、溢出和空白页问题。

## 哪些内容可编辑

| 内容 | DOCX 中的形式 |
|---|---|
| 正文 | Word 段落，可编辑 |
| 标题 | Word 标题段落，可编辑 |
| 公式 | Word OMML 公式，可编辑 |
| 公式编号 | Word 文本和书签，可编辑 |
| 普通图片 | Word 图片对象，可替换或缩放 |
| 表格 | PDF 截图图片，不编辑单元格 |
| 正文引用 | Word 内部跳转 |
| 参考文献 | Word 段落和跳转目标 |

## 重新生成的原则

不要在最终 DOCX 上做长期手工修改。源文件一旦变化，下一次自动生成会覆盖 DOCX。需要长期保留的修改应回写到 LaTeX 源文件。
