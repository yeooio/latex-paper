# 转换脚本使用说明

**本文件夹包含用于生成和更新DOCX文件的Python脚本。**

---

## 📜 脚本清单

### 1. 主转换脚本.py
**用途：** 从LaTeX重新生成完整的DOCX文件

**功能：**
- LaTeX → Markdown → DOCX 完整转换
- 自动插入所有可用的图片
- 生成详细的转换报告

**何时使用：**
- 想从头重新转换
- LaTeX源文件有更新
- 需要重新生成DOCX

**如何运行：**
```bash
cd D:\初稿\latex-paper
python 主转换脚本.py
```

**输出文件：**
- `output/final_docx_conversion/FINAL_thesis_complete_[时间戳].docx`
- `output/final_docx_conversion/CONVERSION_SUMMARY_[时间戳].md`

---

### 2. 补充Oxford面板.py
**用途：** 在现有DOCX中插入Oxford面板图

**功能：**
- 读取最新的FINAL文件
- 插入Oxford面板（figure_4_2_oxford_panel.png）
- 保存为新文件

**何时使用：**
- Agent 3已经生成Oxford面板
- 只需要补充这一个图片

**如何运行：**
```bash
cd D:\初稿\latex-paper
python 补充Oxford面板.py
```

**前提条件：**
- `output/final_docx_conversion/images_processed/figure_4_2_oxford_panel.png` 必须存在
- `output/final_docx_conversion/FINAL_thesis_complete_*.docx` 至少有一个文件

**输出文件：**
- `output/final_docx_conversion/FINAL_thesis_complete_ALL_[时间戳].docx`

---

## 🔧 运行环境要求

### Python版本
- Python 3.7 或更高

### 依赖库
```bash
pip install pandoc python-docx pillow pdf2image
```

**库说明：**
- `pandoc`: 文档格式转换（需要单独安装Pandoc程序）
- `python-docx`: 操作Word文档

### 系统要求
- 操作系统：Windows / Linux / macOS
- 硬盘空间：至少500MB（用于生成文件）
- 内存：至少4GB

## 📝 脚本详细说明

### 主转换脚本.py

#### 工作流程
```
1. LaTeX → Markdown
   ↓
2. Markdown → DOCX（基础版，无图片）
   ↓
3. 收集所有可用的图片
   ↓
4. 智能匹配关键词，插入图片
   ↓
5. 保存最终DOCX
```

#### 图片匹配逻辑
```python
# 伪代码
for paragraph in docx:
    if "Flowchart of the developed SOH" in paragraph.text:
        insert_image_before(paragraph, "figures/fig1.png")
```

#### 输出文件结构
```
output/final_docx_conversion/
├── docx_stages/
│   ├── thesis_[时间].md          ← Markdown中间文件
│   └── base_[时间].docx          ← 基础DOCX（无图）
├── FINAL_thesis_complete_[时间].docx  ← 最终文件
└── CONVERSION_SUMMARY_[时间].md       ← 转换报告
```

---

### 补充Oxford面板.py

#### 工作流程
```
1. 找到最新的FINAL_thesis_complete_*.docx
   ↓
2. 检查Oxford面板是否存在
   ↓
3. 打开DOCX，查找关键词
   ↓
4. 插入Oxford面板图
   ↓
5. 保存为FINAL_thesis_complete_ALL_*.docx
```

#### 关键词匹配
脚本会在DOCX中搜索以下关键词：
- "SOH estimation results"
- "Oxford Cell"
- "estimation errors of different"

找到任一关键词后，在该段落前插入图片。

## 🐛 故障排除

### 问题1：脚本运行失败
**错误信息：** `ModuleNotFoundError: No module named 'docx'`

**解决方案：**
```bash
pip install python-docx
```

---

### 问题2：Pandoc找不到
**错误信息：** `pandoc: command not found`

**解决方案：**
1. 下载Pandoc: https://pandoc.org/installing.html
2. 安装后重启命令行
3. 验证: `pandoc --version`

---

### 问题3：图片没有插入
**可能原因：**
- 图片文件不存在
- 关键词匹配失败
- DOCX文件损坏

**解决方案：**
1. 检查 `output/final_docx_conversion/images_processed/` 确认图片是否存在
2. 打开DOCX，手动搜索关键词，确认文本是否包含
3. 查看脚本输出，确认是否有错误信息

---

### 问题4：Oxford面板还没生成
**错误信息：** `Oxford面板还未生成`

**解决方案：**
等待Agent 3完成。检查方法：
```bash
cd D:\初稿\latex-paper\output\final_docx_conversion\images_processed
dir figure_4_2_oxford_panel.png
```

如果文件不存在，说明Agent还在运行。

## 🎯 高级用法

### 修改图片宽度
编辑脚本，找到这一行：
```python
run.add_picture(str(img_file), width=Mm(150))
```

修改数字 `150` 为你想要的宽度（单位：毫米）。

### 添加新的图片匹配规则
编辑脚本，在图片映射表中添加：
```python
{
    'file': FIGURES_DIR / 'your_image.png',
    'keyword': '你的关键词',
    'width_mm': 150,
    'chapter': 4,
    'type': 'single'
}
```

### 批量处理多个文档
创建批处理脚本：
```bash
#!/bin/bash
for tex_file in *.tex; do
    python 主转换脚本.py "$tex_file"
done
```

## 📚 脚本源码说明

### 主要函数

#### `latex_to_markdown()`
- 调用Pandoc，将LaTeX转换为Markdown
- 使用参数：`--from=latex --to=markdown --standalone --number-sections`

#### `markdown_to_docx(md_file)`
- 调用Pandoc，将Markdown转换为DOCX
- 使用参数：`--from=markdown --to=docx --standalone --number-sections`

#### `collect_available_images()`
- 扫描 `figures/` 和 `images_processed/` 目录
- 生成图片文件列表及对应的关键词

#### `insert_all_images_complete(docx_file, images)`
- 打开DOCX文件
- 遍历所有段落
- 根据关键词匹配插入图片
- 保存更新后的文件

## 🔐 注意事项

### 1. 不要修改原始LaTeX文件
脚本只读取LaTeX文件，不会修改它。但为了安全，建议先备份。

### 2. 生成的DOCX是副本
所有生成的DOCX都是新文件，不会覆盖已有文件。

### 3. 并发运行
不要同时运行多个脚本实例，可能会产生冲突。

### 4. 文件路径
脚本使用绝对路径，确保在正确的目录下运行。
