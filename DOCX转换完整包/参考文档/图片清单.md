## 🔧 图片处理技术说明

### 单独图片（7个）
**处理方式：** 直接使用原始PNG文件

**插入方法：**
1. Python脚本读取DOCX
2. 遍历段落，匹配关键词
3. 在关键词所在段落前插入图片
4. 设置图片宽度为150mm，居中对齐

### 合成面板图（2个）
**处理方式：** Python PIL库合成多个子图

**合成步骤：**
1. 加载所有子图PNG文件
2. 创建大尺寸空白画布（白色背景）
3. 按网格布局排列子图
4. 子图间留白20像素，整体边距30像素
5. 保存为300 DPI的高质量PNG

**Figure 4.2 布局（7个子图）：**
```
┌──────┬──────┬──────┬──────┐
│Cell2 │Cell3 │Cell4 │Cell5 │

│Cell6 │Cell7 │Cell8 │

```

**Figure 4.3 布局（6个子图）：**

## 🛠️ 手动插入图片教程

如果某个图片没有自动插入，按以下步骤手动添加：

### 步骤1：找到插入位置
1. 打开DOCX文件
2. 使用Ctrl+F搜索图片的关键词（见上面每个图片的"位置关键词"）
3. 找到对应的段落

### 步骤2：插入图片
1. 将光标放在段落**上方**（按↑键）
2. 点击 插入 → 图片 → 此设备
3. 选择对应的PNG文件（在`处理后的图片/`文件夹）
4. 插入图片

### 步骤3：调整格式
1. 右键图片 → 环绕文字 → 上下型环绕
2. 右键图片 → 大小和位置
3. 设置宽度：14-16.5cm（根据图片调整）
4. 保持纵横比：勾选
5. 对齐方式：居中

### 步骤4：添加图注（如果没有）
1. 在图片下方输入图注文字
2. 格式：Figure X.X: 图片标题
3. 设置为居中对齐
4. 字号：9-10pt

## 💡 常见问题

### Q1: 为什么有些图片是"面板"？
A: LaTeX中可以精确控制多个子图的排列。转换到DOCX时，我们先把多个子图合成一张大图，再插入。

### Q2: 图片清晰度如何？
A: 所有图片都是300 DPI的高质量PNG，打印效果很好。

### Q3: 可以调整图片大小吗？
A: 可以。在Word中右键图片 → 大小和位置，手动调整宽度。建议保持纵横比。

### Q4: 图片能编辑吗？
A: 图片是位图（PNG），不能编辑内部内容。如需修改，要回到LaTeX源文件重新生成。
